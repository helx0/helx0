# Temporary Profile Site

This repository contains a temporary profile page for GitHub Pages.

Files included:
- `index.html` — main profile page
- `styles.css` — styling for the page

How to publish with GitHub Pages:
1. Open the repository settings.
2. Go to `Pages`.
3. Choose `Branch: main` and `Folder: / (root)`.
4. Save.
5. GitHub will provide a live URL like:
   `https://helx0.github.io/helx0/`

This page currently uses placeholder data and sample project links.
You can later replace the text, email, and links with your real information.

Examples of fields to customize:
- Name
- Short bio
- Email
- LinkedIn URL
- Project titles and links
- Social profile links
